# Proyecto Musk VR 🥽
Mecánica tipo "Simón dice". La tecla espacio, permite generar una secuencia iluminada de 3 bloques.
Seguidamente, el jugador dbe seleccionar estos bloques. Si no se dispone de VR, puede usarse las teclas, por ejemplo:
- "T" para permitir la selección y mover el brazo izqierdo
- "G" para activar la caja seleccionada

Terminada la secuencia, debe apretarse "espacio" de nuevo para generar hasta un total de 3 rondas.
Si el jugador selecciona uan caja erronea, pierde.

---
Versión de Unity: 6.3 LTS (6000.3.12f1)
